# V2.15 무료 사용량 및 후보 선정

- 편도·귀가 모두 방향이 맞고 경로에 가까운 충전소를 최대 8곳(후보가 5곳 이하면 해당 후보 전부)만 실제 경유 계산한다. 직선거리조차 현재 주행가능거리보다 먼 곳은 사전 제외한다. 최종 도달 가능 여부, 도착 여유 50km, 우회 20분 제한은 실제 도로 거리·시간으로 계속 검증한다.
- 슈퍼차저 우선에서는 최대 4곳을 먼저 확보하고 나머지는 경로 근접성 순으로 채운다. 실제 조회 결과 정렬과 추가 충전 제안은 기존 기능을 유지한다.
- 카카오 일반 자동차 길찾기 `/v1/directions`: 공식 무료 일 10,000건. `KAKAO_DIRECTIONS_DAILY_FREE_LIMIT=10000`으로 이 API의 무료 제공량 전체를 허용한다. 임의의 전체 서비스 한도가 아니다. 캐시 적중·동일 요청 합치기는 공급자 호출 예산을 사용하지 않는다.
- Cloudflare Workers Free: 계정 전체 일 100,000 요청, UTC 자정 초기화. 앱에 별도 일 10,000 Worker 요청 제한을 두지 않는다. 목록·오류 리포트 요청은 카카오 예산과 별개다. 기존 분당 악용 방지 제한은 유지한다.
- Cloudflare D1 Free: 일 5,000,000행 읽기·100,000행 쓰기, 총 5GB 저장. 쿼리 수가 아니라 읽고 쓴 행 수 기준. 앱에서 더 낮은 일일 D1 제한을 추가하지 않는다. 캐시로 같은 목록의 반복 읽기를 줄인다.
- 다중 경유지 5,000건, 다중 출발지/목적지 각각 1,000건은 서로 다른 API의 무료 한도이다. 일반 길찾기 한도에 합산하거나 한도 우회용으로 사용하지 않는다. 현재 호출하지 않는 API의 한도를 사용 중이라고 표시하지 않는다.
- 카카오 예산 집계는 이 Worker에서 실행한 호출만 집계한다. 같은 키를 쓰는 다른 Worker·앱의 호출은 합산하지 못한다. 따라서 계정 전체 잔여량을 보장하지 않는다. 실제 계정의 별도 계약·유료 옵션은 확인되지 않았으며 유료 기능을 켜지 않았다.
